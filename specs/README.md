# Specs

Models of atelier's own behaviour, in languages a tool checks rather than a
person reads. Each folder is an experiment: nothing here is a dependency of
atelier, no check here is required to merge, and nothing here runs on a
developer's machine.

| Folder | Holds                                                               |
| ------ | ------------------------------------------------------------------- |
| `tla/` | The command stop-and-clear race, and the two checkers that check it |
